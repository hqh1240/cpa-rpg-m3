# CPA_RPG M3 试玩说明

## 如何运行

1. 打开本目录中的 `index.html`
2. 使用 Chrome、Edge 或其他现代浏览器直接打开即可
3. 无需启动服务器，无需安装依赖

## PWA 安装

- 线上版本支持 PWA，使用 Chrome 或 Edge 打开后可直接安装
- 标题页或设置中出现“安装游戏”按钮时，点击即可安装到桌面或开始菜单
- 首次完整加载后支持离线启动

## 操作方式

- 移动：WASD 或方向键
- 交互：靠近 NPC、怪物、宝箱、采集点后按 `E`
- 鼠标：点击地图目标可移动，点击交互物可触发
- 战斗：普通攻击、技能、道具、逃跑
- 答题：技能攻击会触发 CPA 知识题，答对技能效果更强

## 建议验证内容

- 六区域路线与最终 Boss
- E 交互、房间进出、碰撞
- 战斗、答题、任务交付
- 商店、打造、强化
- 学习报告、错题本、复习挑战
- 每日训练场、技能强化、学习计划开关与连续打卡
- 存档导出/导入
- 音频设置与 BGM
- 动态界面视觉

## 存档说明

- 游戏会自动保存到浏览器本地
- 设置中有导出/导入 JSON 存档
- 清除浏览器数据会清除存档
